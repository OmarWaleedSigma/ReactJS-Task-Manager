 # ReactJS Projects Manager

A React application for organizing projects and keeping track of their work.

## Getting Started

### Prerequisites

- Node.js and npm

### Install

```bash
npm install
```

### Run

Start the application using the development script defined in `package.json`:

```bash
npm run dev
```

## Built With

- ReactJS
- JavaScript XML (JSX)
- Vite
